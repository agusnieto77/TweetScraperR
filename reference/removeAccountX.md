# Eliminar cuentas del pool

Borra las cuentas y sus archivos de sesion.

## Usage

``` r
removeAccountX(accounts)
```

## Arguments

- accounts:

  Nombres de las cuentas a eliminar.

## Value

Invisiblemente, la cantidad de cuentas eliminadas.

## Examples

``` r
if (FALSE) { # \dontrun{
removeAccountX("cuenta2")
} # }
```
